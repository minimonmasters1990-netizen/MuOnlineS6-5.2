# 支持动态OZT称号文件的解决方案

## 问题分析

当前ACuoi_DanhHieu.cpp中的LoadImages方法只支持固定路径和格式的.tga文件：

```cpp
void SEASON3B::CNewUIDanhHieu::LoadImages()
{
    LoadBitmap("Custom\ThangCuoi\RankTitle\nodata.jpg", IMAGE_HD_LOGO_0, GL_LINEAR);

    for (int i = 0; i < gDanhHieu.IsData[2]; i++)
    {
        char IsFile[100];
        sprintf(IsFile, "Custom\ThangCuoi\RankTitle\DanhHieu\%d.tga", i + 1);
        LoadBitmap(IsFile, IMAGE_HD_LOGO_START + i, GL_LINEAR, GL_CLAMP_TO_EDGE);
    }
}
```

**问题**：
1. 只支持.tga格式文件
2. 没有检查文件是否存在的逻辑
3. 不支持动态OZT文件

## 解决方案

### 1. 添加文件存在性检查函数

首先，我们需要添加一个函数来检查文件是否存在：

```cpp
bool FileExists(const char* filename)
{
    DWORD dwAttrib = GetFileAttributesA(filename);
    return (dwAttrib != INVALID_FILE_ATTRIBUTES && !(dwAttrib & FILE_ATTRIBUTE_DIRECTORY));
}
```

### 2. 修改LoadImages方法

修改LoadImages方法，使其能够尝试加载OZT文件，并在OZT文件不存在时回退到.tga文件：

```cpp
void SEASON3B::CNewUIDanhHieu::LoadImages()
{
    LoadBitmap("Custom\ThangCuoi\RankTitle\nodata.jpg", IMAGE_HD_LOGO_0, GL_LINEAR);

    for (int i = 0; i < gDanhHieu.IsData[2]; i++)
    {
        char IsFile[100];
        
        // 尝试加载OZT文件
        sprintf(IsFile, "Custom\ThangCuoi\RankTitle\DanhHieu\%d.ozt", i + 1);
        if (FileExists(IsFile))
        {
            LoadBitmap(IsFile, IMAGE_HD_LOGO_START + i, GL_LINEAR, GL_CLAMP_TO_EDGE);
        }
        else
        {
            // 如果OZT文件不存在，回退到.tga文件
            sprintf(IsFile, "Custom\ThangCuoi\RankTitle\DanhHieu\%d.tga", i + 1);
            LoadBitmap(IsFile, IMAGE_HD_LOGO_START + i, GL_LINEAR, GL_CLAMP_TO_EDGE);
        }
    }
}
```

### 3. 支持动态路径

为了支持更灵活的动态OZT文件，我们可以添加一个配置选项或从服务器获取的路径信息：

```cpp

    {
        char IsFile[256];
        char basePath[256] = "Custom\\ThangCuoi\\RankTitle\\DanhHieu\\";
        
        // 尝试从服务器数据中获取路径（如果有）
        // 这里可以根据实际情况从gDanhHieu.m_LoadData中获取路径信息
        
        // 尝试加载OZT文件

        {
            LoadBitmap(IsFile, IMAGE_HD_LOGO_START + i, GL_LINEAR, GL_CLAMP_TO_EDGE);

        }
    }
}
```

### 4. 优化加载逻辑

## 实现步骤

1. **添加文件存在性检查函数**：在ACuoi_DanhHieu.cpp文件顶部添加FileExists函数

2. **修改LoadImages方法**：
   - 添加对OZT文件的支持
   - 添加文件存在性检查
   - 支持多种文件格式
   - 确保即使文件不存在也能正常运行

3. **测试**：
   - 确保OZT文件存在时能够正确加载
   - 确保OZT文件不存在时能够回退到其他格式
   - 确保所有功能正常工作

## 注意事项

1. **文件路径**：确保OZT文件放在正确的路径下（默认为Custom\ThangCuoi\RankTitle\DanhHieu\）

2. **文件命名**：OZT文件应按照称号等级命名（1.ozt, 2.ozt, 等）

3. **性能考虑**：文件存在性检查可能会稍微影响加载速度，但对于称号系统来说影响不大

4. **兼容性**：确保修改后的代码与现有代码兼容，不会破坏现有功能

通过以上修改，ACuoi_DanhHieu.cpp将能够支持动态OZT称号文件，同时保持对现有.tga文件的兼容性。
