# 修改3D视角平移灵敏度的方案

## 灵敏度分析

通过分析当前代码，我发现灵敏度调整主要体现在以下几个方面：

### 1. 鼠标中键移动灵敏度
- **水平移动**：`0.8 * sensitivity`
- **垂直移动**：`1.3f`（AngleY3D）和`15.f`/`24.f`（AngleZ3D）
- **灵敏度计算**：`float sensitivity = 1.0f - (CameraZoom / -40.0f) * 0.7f;`

### 2. 方向键移动灵敏度
- **左右移动**：`1.5 * sensitivity`
- **上下移动**：`2.0f`（AngleY3D）和`30.f`（AngleZ3D）

### 3. 鼠标滚轮缩放灵敏度
- **缩放速度**：每次滚轮事件调整`CameraZoom` ±3
- **视角调整**：相应调整`AngleY3D` ±1.5f和`AngleZ3D` ±30.f

## 推荐修改值

### 增加平移灵敏度
```cpp
// 鼠标中键水平移动
if (m_CursorX < MouseX) CameraAngle[2] += 1.0 * sensitivity;
if (m_CursorX > MouseX) CameraAngle[2] -= 1.0 * sensitivity;

// 方向键左右移动
if (HIBYTE(GetAsyncKeyState(VK_RIGHT)) == 128) CameraAngle[2] -= 1.8 * sensitivity;
if (HIBYTE(GetAsyncKeyState(VK_LEFT)) == 128) CameraAngle[2] += 1.8 * sensitivity;
```

### 降低平移灵敏度
```cpp
// 鼠标中键水平移动
if (m_CursorX < MouseX) CameraAngle[2] += 0.6 * sensitivity;
if (m_CursorX > MouseX) CameraAngle[2] -= 0.6 * sensitivity;

// 方向键左右移动
if (HIBYTE(GetAsyncKeyState(VK_RIGHT)) == 128) CameraAngle[2] -= 1.2 * sensitivity;
if (HIBYTE(GetAsyncKeyState(VK_LEFT)) == 128) CameraAngle[2] += 1.2 * sensitivity;
```

### 调整灵敏度随缩放的变化
```cpp
// 增加灵敏度随缩放的变化
float sensitivity = 1.0f - (CameraZoom / -40.0f) * 0.8f;

// 减少灵敏度随缩放的变化
float sensitivity = 1.0f - (CameraZoom / -40.0f) * 0.5f;
```

## 注意事项

1. **平衡调整**：水平和垂直灵敏度应保持适当比例，以确保操作手感一致
2. **缩放级别**：灵敏度调整应考虑不同缩放级别的操作需求
3. **测试验证**：修改后应在游戏中测试不同场景下的操作手感
4. **范围限制**：确保灵敏度调整不会导致视角变化过快或过慢

通过以上修改，您可以根据个人喜好和操作习惯调整3D视角的平移灵敏度，获得更流畅的游戏体验。
