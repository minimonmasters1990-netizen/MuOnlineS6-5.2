# 支持16帧OZT精灵图动态显示的解决方案

## 问题分析

用户的OZT文件包含单个TGA文件，该TGA文件是16帧的精灵图（sprite sheet），需要实现逐格显示的动态效果。当前代码只支持静态TGA文件的显示，不支持精灵图的逐帧动画。

## 解决方案

### 1. OZT文件格式定义

OZT文件格式如下（文本格式）：
```
1
Custom\ThangCuoi\RankTitle\DanhHieu\1.tga
16
4
4
1000
```

解释：
- 1: TGA文件数量（固定为1）
- Custom\ThangCuoi\RankTitle\DanhHieu\1.tga: TGA文件路径
- 16: 总帧数（用户指定）
- 4: 行数（16帧最常见的排列是4x4）
- 4: 列数
- 1000: 切换间隔（毫秒）

### 2. 修改OZTFileInfo结构

```cpp
struct OZTFileInfo
{
    std::string tgaFile;    // 单个TGA文件路径
    int frameCount;         // 总帧数
    int rows;               // 行数
    int cols;               // 列数
    int switchInterval;     // 切换间隔（毫秒）
    bool isSpriteSheet;     // 是否为精灵图
};
```

### 3. 修改ParseOZTFile函数

```cpp
OZTFileInfo ParseOZTFile(const char* oztPath)
{
    OZTFileInfo info;
    info.switchInterval = 1000; // 默认1秒
    info.frameCount = 1;
    info.rows = 1;
    info.cols = 1;
    info.isSpriteSheet = false;
    
    FILE* file = fopen(oztPath, "r");
    if (!file)
        return info;
    
    int tgaCount = 0;
    fscanf(file, "%d", &tgaCount);
    
    char buffer[256];
    fgets(buffer, sizeof(buffer), file); // 读取换行符
    
    if (tgaCount > 0)
    {
        fgets(buffer, sizeof(buffer), file);
        // 移除换行符
        buffer[strcspn(buffer, "\r\n")] = 0;
        if (strlen(buffer) > 0)
        {
            info.tgaFile = std::string(buffer);
        }
    }
    
    // 读取精灵图信息
    fscanf(file, "%d", &info.frameCount);
    fscanf(file, "%d", &info.rows);
    fscanf(file, "%d", &info.cols);
    fscanf(file, "%d", &info.switchInterval);
    
    info.isSpriteSheet = (info.frameCount > 1);
    
    fclose(file);
    return info;
}
```

void SEASON3B::CNewUIDanhHieu::LoadImages()
{
    LoadBitmap("Custom\ThangCuoi\RankTitle\nodata.jpg", IMAGE_HD_LOGO_0, GL_LINEAR);

    for (int i = 0; i < gDanhHieu.IsData[2]; i++)
    {
        char IsFile[256];
        
        // 尝试加载OZT文件
        sprintf(IsFile, "Custom\ThangCuoi\RankTitle\DanhHieu\%d.ozt", i + 1);
        if (FileExists(IsFile))
        {
            // 解析OZT文件
            OZTFileInfo oztInfo = ParseOZTFile(IsFile);
            gDanhHieu.m_OZTInfo[i + 1] = oztInfo;
            gDanhHieu.m_CurrentFrameIndex[i + 1] = 0;
            gDanhHieu.m_LastSwitchTime[i + 1] = GetTickCount();
            
            // 加载TGA文件
            if (!oztInfo.tgaFile.empty())
            {
                LoadBitmap(oztInfo.tgaFile.c_str(), IMAGE_HD_LOGO_START + i, GL_LINEAR, GL_CLAMP_TO_EDGE);
            }
        }
        else
        {
            // 如果OZT文件不存在，回退到.tga文件
            sprintf(IsFile, "Custom\ThangCuoi\RankTitle\DanhHieu\%d.tga", i + 1);
            LoadBitmap(IsFile, IMAGE_HD_LOGO_START + i, GL_LINEAR, GL_CLAMP_TO_EDGE);
        }
    }
}

    if (!this->IsCurrentLevel) return;

    // OZT精灵图动画逻辑
    DWORD currentTime = GetTickCount();
    if (this->IsData[1] > 0)
    {
        auto oztIter = m_OZTInfo.find(this->IsData[1]);
        if (oztIter != m_OZTInfo.end() && oztIter->second.isSpriteSheet)
        {
            auto& oztInfo = oztIter->second;
            auto& currentFrame = m_CurrentFrameIndex[this->IsData[1]];
            auto& lastSwitchTime = m_LastSwitchTime[this->IsData[1]];
            
            // 检查是否需要切换帧
            if (currentTime - lastSwitchTime >= oztInfo.switchInterval)
            {
                lastSwitchTime = currentTime;
                currentFrame = (currentFrame + 1) % oztInfo.frameCount;
            }
        }
    }

    if (this->IsData[1] < this->IsNextLevel->AllData[10] + 1)

        if (this->IsData[1] != 0)

## 注意事项

1. **TGA文件要求**：确保TGA文件是正确的精灵图格式，16帧排列为4x4网格

2. **文件路径**：确保OZT文件和TGA文件放在正确的路径下（默认为Custom\ThangCuoi\RankTitle\DanhHieu\）

3. **性能考虑**：精灵图动画可能会稍微影响性能，但对于称号系统来说影响不大

4. **兼容性**：确保修改后的代码与现有代码兼容，不会破坏现有功能
