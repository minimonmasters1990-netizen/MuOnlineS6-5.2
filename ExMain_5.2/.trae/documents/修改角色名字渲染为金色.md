## 修改角色名字渲染为金色（保持PK红色不变）

### 问题分析
角色名字的渲染颜色由 `SetPlayerColor` 函数控制，该函数位于 `ZzzInterface.cpp` 文件中。当前函数根据玩家的 PK 值来设置不同的颜色：
- PK 0-2: 蓝色
- PK 3: 白色
- PK 4: 橙色（杀人1命）
- PK 5: 红色（杀人2命）
- 默认: 红色

### 解决方案
修改 `SetPlayerColor` 函数，将非PK角色（PK 0-3）的名字改为金色，同时保持PK角色（PK 4-5）的红色不变。

### 具体修改步骤
1. **定位文件**：`d:\SRC2-2基本完美\ExMain_5.2\Main5.2\ZzzInterface.cpp`
2. **找到函数**：`SetPlayerColor` 函数（第 786 行附近）
3. **修改函数**：将 PK 0-3 的颜色设置为金色（RGB: 255, 215, 0），保持 PK 4-5 的颜色不变
4. **验证修改**：确保修改后的函数能够正确编译和运行

### 修改后的函数代码
```cpp
void SetPlayerColor(BYTE PK)
{
    switch (PK)
    {
        case 0:g_pRenderText->SetTextColor(255, 215, 0, 255); break; // 金色
        case 1:g_pRenderText->SetTextColor(255, 215, 0, 255); break; // 金色
        case 2:g_pRenderText->SetTextColor(255, 215, 0, 255); break; // 金色
        case 3:g_pRenderText->SetTextColor(255, 215, 0, 255); break; // 金色
        case 4:g_pRenderText->SetTextColor(255, 150, 60, 255); break; // 保持橙色（杀人1命）
        case 5:g_pRenderText->SetTextColor(255, 80, 30, 255); break; // 保持红色（杀人2命）
        default:g_pRenderText->SetTextColor(255, 215, 0, 255); break; // 金色
    }
}
```

这样修改后，非PK角色的名字会显示为金色，而PK角色的名字会保持红色，符合用户的要求。
