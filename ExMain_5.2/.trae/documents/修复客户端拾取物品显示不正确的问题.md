## 问题分析

在 `WSclient.cpp` 文件的 `ReceiveGetItem` 函数中，当玩家拾取物品时，显示的物品名称是从 `Items[ItemKey].Item` 中获取的，而不是从服务器发送的 `Data->Item` 中获取的。这导致了客户端拾取时显示的物品不正确的问题。

具体来说，在代码的第 5672-5673 行：

```cpp
int level = (Items[ItemKey].Item.Level >> 3) & 15;
GetItemName(Items[ItemKey].Item.Type, level, szItem);
```

这里使用的是 `Items[ItemKey].Item`，而不是 `Data->Item`。

## 修复方案

修改 `ReceiveGetItem` 函数，使用服务器发送的 `Data->Item` 来获取物品信息，而不是使用客户端存储的 `Items[ItemKey].Item`。

具体修改步骤：

1. 在 `ReceiveGetItem` 函数中，当处理非金币物品时，从 `Data->Item` 中提取物品类型和等级
2. 使用提取的类型和等级调用 `GetItemName` 函数获取正确的物品名称
3. 保持其他逻辑不变

## 修复代码

需要修改的文件：`d:\SRC ThangCuoi\SRC\ExMain_5.2\Main5.2\WSclient.cpp`

修改内容：

将第 5672-5673 行：

```cpp
int level = (Items[ItemKey].Item.Level >> 3) & 15;
GetItemName(Items[ItemKey].Item.Type, level, szItem);
```

修改为：

```cpp
int Type = ConvertItemType(Data->Item);
BYTE Level = Data->Item[1] & 0xf;
GetItemName(Type, Level, szItem);
```

这样，客户端拾取物品时就会显示服务器发送的实际物品信息，而不是客户端存储的可能不正确的信息。
