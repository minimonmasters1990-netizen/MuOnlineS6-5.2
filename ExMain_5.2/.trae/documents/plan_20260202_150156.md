# 在角色名下方显示血条

## 实现目标
在游戏主界面中，在玩家自己的角色名下方显示一个血条，显示当前生命值状态，不需要通过组队也能显示。

// 玩家自己的血条渲染
if (c->Owner == Hero && c->Owner->Object.Live)

### 3. 实现细节

#### 3.1 血条位置
- **位置**：在角色名下方，与角色名对齐
- **X坐标**：使用 `x` 参数，与角色名的X坐标相同
- **Y坐标**：使用 `y + c->Height + 2`，在角色名下方2像素的位置
- **宽度**：使用 `c->Width`，与角色名的宽度相同

#### 3.2 血条样式
- **血条背景**：使用 `IsToolKit.RenderToolTip` 渲染血条背景
- **血条**：使用 `RenderImage` 函数渲染血条，使用 `SEASON3B::CNewUIPartyInfoWindow::IMAGE_PARTY_HPBAR` 图像
- **护盾条**：使用 `RenderImage` 函数渲染护盾条，使用 `SEASON3B::CNewUIMessageBoxMng::IMAGE_MSGBOX_PROGRESS_BAR` 图像

#### 3.3 血条颜色
- **血条颜色**：根据生命值百分比自动变化
  - 80%+：绿色
  - 60%-80%：黄绿色
  - 50%-60%：黄色
  - 50%-：红色（闪烁）

### 4. 技术实现

#### 4.1 血条数据获取
- **血条数据**：使用 `gClassLifeBar.Get()` 函数获取血条数据
- **生命值**：`lpNewHealthBar->rate`
- **护盾值**：`lpNewHealthBar->rate2`

#### 4.2 血条渲染流程
1. **计算血条位置**：根据角色名位置计算血条位置
2. **获取血条数据**：获取当前生命值和护盾值
3. **计算百分比**：计算生命值和护盾值的百分比
4. **渲染血条背景**：渲染血条的背景
5. **渲染血条**：根据生命值百分比渲染血条
6. **渲染护盾条**：根据护盾值百分比渲染护盾条

### 5. 实现步骤

1. **修改 ZzzInterface.cpp**：修改 `RenderBoolean` 函数，添加玩家自己血条的渲染代码
2. **测试血条显示**：确保血条只在玩家自己的角色名下方显示，并且总是显示
3. **调整血条样式**：确保血条样式与其他玩家的血条样式一致

### 6. 优化和兼容性
- **确保血条只在玩家自己的角色名下方显示**，不影响其他角色
- **血条颜色根据生命值百分比变化**：绿色 → 黄色 → 红色（闪烁）
- **血条位置**：在角色名下方，与角色名对齐
- **血条大小**：根据角色名大小自动调整
- **血条总是显示**：不受安全区域的限制

## 总结

通过修改 `RenderBoolean` 函数，我们可以在玩家自己的角色名下方显示一个血条，实时反映当前生命值状态。血条颜色会根据生命值百分比自动变化，从绿色到黄色再到红色（闪烁），提供直观的视觉反馈。

这种实现方式不需要修改组队系统，也不会影响其他角色的显示，只在玩家自己的角色名下方显示血条，完全符合需求。
