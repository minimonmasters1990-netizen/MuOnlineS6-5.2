# 显示自己角色血条的修改计划

## 问题分析

当前血条显示逻辑存在以下问题：

1. 只能显示其他玩家的血条，不能显示自己的血条
2. 血条显示需要满足多个条件，包括选中角色、不在安全区域等
3. 缺少对自己角色（`Hero`）血条的专门处理

## 解决方案

### 核心修改思路

修改 `ClassLifeBar::Render()` 方法，添加对自己角色（`Hero`）血条的专门渲染逻辑，使其：

1. 无论是否被选中都能显示血条
2. 在安全区域内也能显示血条
3. 保持其他玩家和怪物血条的原有显示逻辑不变

### 具体修改步骤

1. **修改** **`HealthyBar.cpp`** **文件**：

   * 保留对选中角色的血条显示逻辑（包括怪物和其他玩家）

   * 添加对自己角色（`Hero`）血条的专门渲染逻辑

   * 确保自己角色血条的渲染位置正确

   * 移除自己角色血条的 `SafeZone` 检查

2. **修改** **`ClassLifeBar::Render()`** **方法**：

   * 在现有逻辑基础上，添加对 `Hero` 角色的血条渲染

   * 为 `Hero` 角色计算正确的屏幕坐标

   * 确保 `Hero` 角色血条数据的获取和处理

   * 跳过已经处理过的 `Hero` 角色（如果 `Hero` 正好是选中角色）

3. **保持兼容性**：

   * 保留对 `SelectedCharacter` 的处理，确保原有选中角色的血条显示逻辑不变

   * 保持对 `g_bRenderNameMonster` 的检查，确保可以通过全局开关控制血条显示

   * 保持怪物和其他玩家血条的原有显示逻辑不变

## 技术实现细节

### 具体修改代码

```cpp
void ClassLifeBar::Render()
{
    const float Width = 38.f;
    char Text[100], RateHP[100];

    if (!g_bRenderNameMonster)
        return;

    EnableAlphaTest();
    glColor4f(1.f, 1.f, 1.f, 1.f);

    // 1. 处理选中角色的血条（保持原有逻辑，包括怪物和其他玩家）
    if (SelectedCharacter != -1)
    {
        CHARACTER* c = &CharactersClient[SelectedCharacter];
        OBJECT* o = &c->Object;
        vec3_t Position;
        int ScreenX, ScreenY;

        Vector(o->Position[0], o->Position[1], o->Position[2] + o->BoundingBoxMax[2] + 100.f, Position);
        Projection(Position, &ScreenX, &ScreenY);
        ScreenX -= static_cast<int>(Width / 2);

        if (!o->Live || c->Object.Kind == KIND_NPC)
            return;

        ClassLifeData* lpNewHealthBar = Get(c->Key, c->Object.Kind);
        if (lpNewHealthBar == nullptr)
            return;

        int LifePercent = lpNewHealthBar->rate / 1.8;
        int ShieldPercent = lpNewHealthBar->rate2 / 1.8;
        float iHP = static_cast<float>(LifePercent);

        if (c->Dead != 0)
        {
            iHP -= c->Dead;
            if (iHP < 0)
                iHP = 0;
        }

        int ModelMonster = gCustomModelNPC.IsMonster(c->MonsterIndex);
        int MonsterClass = IsToolKit.GetIndexMonster(c->MonsterIndex);

        if (MonsterClass || ModelMonster || c->MonsterIndex == 34 || c->Object.SubType == MODEL_SKELETON1 || c->Object.SubType == MODEL_SKELETON2 || c->Object.SubType == MODEL_SKELETON3 || c->Object.Kind == KIND_MONSTER && c->Object.Type != MODEL_PLAYER && c->Object.Kind != KIND_TRAP)
        {
            // 怪物血条渲染逻辑（保持不变）
            char DisplayText[128];
            sprintf(DisplayText, "%s - %d%%", c->ID, lpNewHealthBar->rate);

            g_pRenderText->SetFont(g_hFont);
            g_pRenderText->SetBgColor(0);
            g_pRenderText->SetTextColor(255, 255, 255, 255);
            g_pRenderText->RenderText(ScreenX - 86, ScreenY - 7, DisplayText, 200, 0, RT3_SORT_CENTER);

            IsToolKit.RenderToolTip(ScreenX - 15.f, ScreenY + 3.f, 55.f, 3.2f);
            EnableAlphaTest();

            float r, g, b;
            GetHPColorByRate(lpNewHealthBar->rate, r, g, b);
            glColor3f(r, g, b);
            RenderColor((ScreenX - 17) + 2, (ScreenY - 6) + 9, iHP, 3);
            glEnable(GL_TEXTURE_2D);
            glColor3f(1.0f, 1.0f, 1.0f);
        }
        else
        {
            // 其他玩家血条渲染逻辑（保持不变）
            if (!c->SafeZone)
            {
                IsToolKit.RenderToolTip(ScreenX - 15.f, ScreenY + 3.f, 55.f, 3.2f);
                RenderImage(SEASON3B::CNewUIPartyInfoWindow::IMAGE_PARTY_HPBAR, (ScreenX - 17) + 2, (ScreenY - 6) + 9, iHP, 3);
                RenderImage(SEASON3B::CNewUIMessageBoxMng::IMAGE_MSGBOX_PROGRESS_BAR, (ScreenX - 17) + 2, (ScreenY - 6) + 9, ShieldPercent, 3);
            }
        }
    }

    // 2. 为自己的角色（Hero）渲染血条（新增逻辑）
    if (Hero != nullptr && Hero->Object.Live)
    {
        CHARACTER* c = Hero;
        OBJECT* o = &c->Object;

        // 跳过已处理的选中角色
        if (SelectedCharacter != -1 && &CharactersClient[SelectedCharacter] == c)
        {
            goto EndRender;
        }

        // 获取血条数据
        ClassLifeData* lpNewHealthBar = Get(c->Key, c->Object.Kind);
        if (lpNewHealthBar == nullptr)
        {
            goto EndRender;
        }

        // 计算屏幕坐标
        vec3_t Position;
        int ScreenX, ScreenY;
        Vector(o->Position[0], o->Position[1], o->Position[2] + o->BoundingBoxMax[2] + 100.f, Position);
        Projection(Position, &ScreenX, &ScreenY);
        ScreenX -= static_cast<int>(Width / 2);

        // 计算生命值和护盾值
        int LifePercent = lpNewHealthBar->rate / 1.8;
        int ShieldPercent = lpNewHealthBar->rate2 / 1.8;
        float iHP = static_cast<float>(LifePercent);

        if (c->Dead != 0)
        {
            iHP -= c->Dead;
            if (iHP < 0)
                iHP = 0;
        }

        // 渲染自己角色的血条（移除 SafeZone 检查）
        IsToolKit.RenderToolTip(ScreenX - 15.f, ScreenY + 3.f, 55.f, 3.2f);
        RenderImage(SEASON3B::CNewUIPartyInfoWindow::IMAGE_PARTY_HPBAR, (ScreenX - 17) + 2, (ScreenY - 6) + 9, iHP, 3);
        RenderImage(SEASON3B::CNewUIMessageBoxMng::IMAGE_MSGBOX_PROGRESS_BAR, (ScreenX - 17) + 2, (ScreenY - 6) + 9, ShieldPercent, 3);
    }

EndRender:
    DisableAlphaBlend();
    glColor4f(1.0f, 1.0f, 1.0f, 1.0f);
}
```

## 关键修改点

1. **添加对 Hero 的专门处理**：添加对 `Hero` 角色的血条渲染逻辑，确保自己的血条能显示

2. **跳过重复处理**：如果 `Hero` 正好是选中角色，跳过重复处理

3. **移除 SafeZone 检查**：自己角色的血条在安全区域内也能显示

4. **保持兼容性**：保留对其他玩家和怪物血条的原有显示逻辑不变

## 预期效果

* **自己的角色**：血条将始终显示，无论是否被选中，无论是否在安全区域内

* **其他玩家**：血条显示逻辑保持不变，需要满足原有条件

* **怪物**：血条显示逻辑保持不变，需要满足原有条件

* **性能影响**：由于只需要额外渲染一个自己角色的血条，性能影响可以忽略不计
