# 在角色名下方显示玩家血条

## 实现目标

在游戏主界面中，在玩家自己的角色名下方显示一个血条，显示当前生命值状态，不需要通过组队也能显示。

## 实现方案

### 1. 找到血条渲染的关键函数

* **修改文件**：`d:\SRC2-2基本完美\ExMain_5.2\Main5.2\ZzzInterface.cpp`

* **修改函数**：`RenderBoolean` 函数

### 2. 实现血条渲染逻辑

在 `RenderBoolean` 函数中，在渲染玩家角色名后添加血条渲染代码：

1. **检查是否是玩家自己**：判断 `c->Owner == Hero`
2. **获取生命值数据**：获取玩家当前生命值和最大生命值
3. **计算生命值百分比**：根据当前生命值和最大生命值计算百分比
4. **计算血条长度**：根据百分比计算血条的显示长度
5. **渲染血条**：在角色名下方渲染血条，使用与组队血条相同的绘制方式

### 3. 血条渲染代码

```cpp
// 玩家自己的血条渲染
if (c->Owner == Hero && c->Owner->Object.Live)
{
    // 获取血条数据
    ClassLifeData* lpNewHealthBar = Get(c->Owner->Key, c->Owner->Object.Kind);
    if (lpNewHealthBar != nullptr)
    {
        // 计算生命值百分比
        int LifePercent = lpNewHealthBar->rate / 1.8;
        float iHP = static_cast<float>(LifePercent);
        
        // 计算血条位置
        int BarX = RenderPos.x;
        int BarY = RenderPos.y + 2;
        int BarWidth = c->Width;
        
        // 渲染血条背景
        IsToolKit.RenderToolTip(BarX, BarY, BarWidth, 3.2f);
        
        // 渲染血条
        RenderImage(SEASON3B::CNewUIPartyInfoWindow::IMAGE_PARTY_HPBAR, BarX, BarY, iHP, 3);
        
        // 渲染护盾条
        int ShieldPercent = lpNewHealthBar->rate2 / 1.8;
        RenderImage(SEASON3B::CNewUIMessageBoxMng::IMAGE_MSGBOX_PROGRESS_BAR, BarX, BarY, ShieldPercent, 3);
    }
}
```

### 4. 实现细节

* **血条位置**：在角色名下方，与角色名对齐

* **血条大小**：宽度与角色名宽度相同，高度约为3像素

* **血条样式**：使用与组队血条相同的样式

* **血条数据**：使用与组队血条相同的数据来源

* **显示条件**：只在玩家自己的角色名下方显示，且角色必须活着

### 5. 优化和兼容性

* 确保血条只在玩家自己的角色名下方显示

* 确保血条的渲染不影响其他游戏元素

* 确保血条在不同分辨率下都能正确显示

* 确保血条在角色死亡时不显示
