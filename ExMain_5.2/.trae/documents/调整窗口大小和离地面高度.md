# 调整窗口大小和离地面高度的方案

## 一、调整窗口大小

### 头衔系统窗口大小调整

在 `ACuoi_DanhHieu.cpp` 文件中，窗口大小是在构造函数中设置的：

```cpp
WINDOW_WIDTH = 270;
WINDOW_HEIGHT = 200;
```

**修改方法**：直接修改这两个值来调整窗口的宽度和高度。

## 二、调整离地面高度

在 `Camera3D.cpp` 文件中，离地面高度主要由以下变量控制：

1. **AngleZ3D** - 直接控制视角的高度
2. **AngleY3D** - 控制视角的俯仰角度
3. **CameraZoom** - 控制视角的远近

### 相关限制和调整参数

1. **AngleZ3D 范围限制**：

   ```cpp
   const float MIN_ANGLE_Z3D = -1000.0f;
   const float MAX_ANGLE_Z3D = 500.0f;
   ```

2. **AngleY3D 范围限制**：

   * 向上最大角度：20度

   * 向下最大角度：-45度

3. **CameraZoom 范围限制**：

   * 最小：-40（最靠近）

   * 最大：12（最远离）

### 调整方法

1. **修改视角高度限制**：

   * 调整 `MIN_ANGLE_Z3D` 和 `MAX_ANGLE_Z3D` 的值

   * 增大 `MAX_ANGLE_Z3D` 可以提高离地面高度

2. **修改视角俯仰角度限制**：

   * 调整 `AngleY3D` 的上下限

   * 增大向上角度限制可以让视角更高

3. **修改鼠标和键盘控制灵敏度**：

   * 调整鼠标移动和键盘按键对应的角度变化值

4. **修改默认视角**：

   * 在 `Restore()` 函数中修改默认的视角参数

## 三、具体调整步骤

1. **确定需要调整的具体窗口**：

   * 确认是头衔系统窗口还是其他窗口

2. **调整窗口大小**：

   * 找到对应窗口的宽度和高度定义

   * 修改相应的值

3. **调整离地面高度**：

   * 根据需要调整 `Camera3D.cpp` 中的相关参数

   * 测试调整效果，确保视角不会进入地下或过高

4. **测试验证**：

   * 运行游戏，测试窗口大小和视角高度的调整效果

   * 确保所有功能正常工作
